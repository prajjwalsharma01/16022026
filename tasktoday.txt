Call stack:

A call stack is a data structure used by a program to keep track of function calls. 


Base case vs recursive case

Base case is the condition where the function stop calling to itself or recursion stop . 
recursive case is the part of the function where function call itself to solve a smaller piece of problem . 


Stack overflow :
A stack overflow occurs when a program uses more stack memory than is available,
usually because too many function calls are placed on the call stack without returning.
